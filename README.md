# pricing-lab

Plateforme interactive de produits financiers : un catalogue de dérivés et de produits
structurés (options, obligations, autocall Phoenix…) avec prix et sensibilités en direct,
puis la construction et l'analyse de risque d'un portefeuille.

Projet personnel de deux étudiants de première année du Magistère BFA (Université Paris Dauphine-PSL).

## Lancer le projet

À compléter (premier exercice).

## Structure

- `Accueil.py` et `pages/` : l'application Streamlit
- `pricing/` : le moteur de pricing
- `tests/` : les tests, lancés avec `python -m pytest`
